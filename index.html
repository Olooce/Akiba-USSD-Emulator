How to use

  • Dial *144#, then press Call or the left soft key.
  • Type a menu number and press Send (left soft key, Call or OK).
  • Reply 0 to go back. The right soft key clears a digit, or cancels when the reply is empty.
  • End closes the session.
  • Keyboard: digits, * #, Enter = Call, Esc = End, Backspace = Clear.
